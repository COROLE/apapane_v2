# アカウント削除

最終更新日: 2026-03-29

Apapane では、保護者向けメニューからサインイン済みアカウントの削除を行えます。

## 削除手順

1. 親向けメニューを開く
2. プロフィール編集画面へ進む
3. `アカウント削除` を選択する
4. アプリが認証済みの `deleteAccount` Cloud Function を呼び出す

## 削除対象

削除完了後、以下のデータを削除します。

- Firebase Authentication 上の該当アカウント
- `users/{uid}` 配下の Firestore データ
- `users/{uid}/` 配下の Cloud Storage データ

## ご注意

- ゲスト利用中は、サインイン済みアカウントが存在しないため、アカウント削除の対象はありません。
- ストア課金の請求停止やサブスクリプション解約は、App Store または Google Play のアカウント管理画面で別途行ってください。
- 障害調査や法令対応のため、最小限のログが一時的に残る場合があります。
