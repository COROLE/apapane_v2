# プライバシーポリシー

最終更新日: 2026-03-29

株式会社COROLE（以下「当社」といいます。）は、モバイルアプリ「Apapane」（以下「本サービス」といいます。）における利用者情報の取扱いについて、以下のとおり定めます。

## 1. 事業者情報

- 事業者名: 株式会社COROLE
- サービス名: Apapane
- お問い合わせ先: `contact@corole.co.jp`
- プライバシーポリシー URL: `https://corole.net/apapane/privacy`
- 利用規約 URL: `https://corole.net/apapane/terms`
- アカウント削除案内 URL: `https://corole.net/apapane/account-deletion`

## 2. 本サービスの概要

Apapane は、子ども向けのやさしい物語体験を想定した、AI ストーリー生成アプリです。初回公開版では、ゲストのまま物語づくりを試すことができ、親向けメニューからサインイン、課金、外部リンクの利用、プロフィール編集等を行えます。

## 3. 取得する情報

当社は、以下の情報を取得または処理します。

### 3-1. アカウント・識別情報

- Firebase Authentication による利用者識別情報
- ゲスト利用時の匿名認証情報またはローカルセッション識別子
- Google サインインまたは Apple サインインにより取得されるアカウント情報
  - 氏名または表示名
  - メールアドレス
  - プロフィール画像 URL

### 3-2. 利用者が入力・作成する情報

- 物語生成のために入力したテキスト
- AI により生成された物語本文、タイトル、画像
- 保存した作品、お気に入り情報
- プロフィール編集時に設定した表示名、プロフィール画像

### 3-3. 課金・購入関連情報

- 商品 ID
- 購入 ID
- 購入確認に必要なストアの検証情報
- コイン残高、サブスクリプション状態、有効期限等の権利情報

### 3-4. 音声・画像関連情報

- マイク入力を用いた音声認識結果のテキスト
- プロフィール設定のために利用者が選択した写真

本サービスは、音声入力補助のために音声認識機能を利用しますが、音声ファイル自体を恒常的に保存する設計ではありません。

### 3-5. 診断・セキュリティ関連情報

- クラッシュ診断情報
- App Check 等の不正利用防止用トークン情報
- レート制限・安全対策のためのログ
- 退会、購入検証、AI 生成処理に関する最小限の監査ログ

## 4. 利用目的

当社は、取得した情報を以下の目的で利用します。

- 利用者認証、ゲストセッション維持、アカウント管理のため
- 物語、画像、音声の生成および保存のため
- 作品・プロフィール・購入権利を端末間で同期するため
- 購入検証、復元、サブスクリプション管理のため
- 不正利用防止、レート制限、安全対策のため
- 障害調査、品質改善、問い合わせ対応のため
- 法令遵守または権利保護のため

## 5. 外部サービスの利用

本サービスでは、以下の外部サービスを利用します。

- Firebase Authentication
- Cloud Firestore
- Cloud Storage
- Cloud Functions
- Firebase App Check
- Firebase Crashlytics
- Google Sign-In
- Sign in with Apple
- Google Gemini API
- Google Cloud Text-to-Speech
- Apple App Store / Google Play による課金基盤

これらの提供事業者において、各社のプライバシーポリシーや利用条件に従って情報が処理される場合があります。

## 6. 第三者提供

当社は、次の場合を除き、利用者情報を第三者に提供しません。

- 利用者が希望した機能提供のために、前条の外部サービス提供者へ必要な範囲で連携する場合
- 法令に基づく場合
- 人の生命、身体または財産の保護のために必要がある場合
- 不正利用対策、権利保護、システム保守のために合理的に必要な場合

## 7. 保存期間

- ゲスト利用に関するローカルセッション情報は、端末上に保存され、アプリ削除、セッション消去、またはアカウント切替により消える場合があります。
- サインイン済みアカウントの作品、プロフィール、購入権利情報は、退会または削除依頼まで保存されます。
- 退会後は、Firebase Authentication 上のアカウント、`users/{uid}` 配下の Firestore データ、`users/{uid}/` 配下の Cloud Storage データを削除します。
- セキュリティまたは障害対応のための最小限のログは、合理的な期間保持される場合があります。

## 8. 子どもの利用と保護者向け機能

- 本サービスは、子ども向け体験を含みますが、サインイン、課金、外部リンクの利用は親向けメニューから行う設計です。
- 初回公開版では公開作品フィードを提供せず、作品の一般公開は想定していません。
- 保護者の方は、プロフィール編集画面から退会手続きを行うことができます。

## 9. 利用者の権利

利用者または保護者は、法令の範囲で、当社に対し以下を求めることができます。

- 保有する利用者情報に関する問い合わせ
- 訂正、削除、利用停止等の請求
- 退会によるアカウント削除

お問い合わせは `contact@corole.co.jp` までご連絡ください。

## 10. 安全管理

当社は、App Check、認証制御、レート制限、権限制御、クラッシュ診断等を用いて、不正利用防止および安全管理に努めます。ただし、通信環境、第三者サービス、端末設定その他の事情により、完全な安全性を保証するものではありません。

## 11. 改定

当社は、法令改正、機能変更、運用変更等に応じて本ポリシーを改定することがあります。重要な変更がある場合は、アプリ内表示、公開ページの更新、または適切な方法で周知します。
