# Apapane

Apapane is a Flutter application for generating and sharing story content.

## Internal Deployment

The repository is set up for internal beta delivery through:

- Google Play internal testing
- App Store Connect TestFlight internal testing

See [docs/internal-deployment.md](docs/internal-deployment.md) for the one-time store setup, GitHub secrets, and GitHub Actions workflow details.
Use [docs/internal-smoke-checklist.md](docs/internal-smoke-checklist.md) to record each Android internal / TestFlight verification pass.
